MOOVIE — BROWSER EXTENSION LISTING
==================================

SUPPORTED BROWSERS
• Google Chrome (Chrome Web Store or load unpacked)
• Microsoft Edge (Edge Add-ons or Chrome Web Store)
• Opera (Chrome Web Store or load unpacked)
• Brave, Vivaldi, and other Chromium MV3 browsers (load unpacked)
• Mozilla Firefox 109+ (about:debugging → Load Temporary Add-on, or Firefox Add-ons)

STORE PACKAGES (upload these ZIPs — manifest.json is at ZIP root)
• Chrome:  watchable/extension/dist/moovie-chrome.zip
• Edge:    watchable/extension/dist/moovie-edge.zip
• Opera:   watchable/extension/dist/moovie-opera.zip
• Firefox: watchable/extension/dist/moovie-firefox.zip
• Brave / Vivaldi sideload: moovie-brave.zip or moovie-vivaldi.zip

Rebuild all packages:
  cd watchable/extension && ./package.sh

INSTALL (UNPACKED / DEVELOPER)
1. Open browser extension page (chrome://extensions, edge://extensions, about:debugging#/runtime/this-firefox, or opera://extensions)
2. Enable Developer mode (Chromium) or use "Load Temporary Add-on" (Firefox)
3. Select watchable/extension/manifest.json
4. Reload after code changes
